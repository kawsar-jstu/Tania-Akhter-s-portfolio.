TANIA AKHTER — PERSONAL PORTFOLIO

This portfolio uses plain HTML, CSS, and JavaScript and is intended to be easy to edit.

PAGES
- index.html       Home (profile photo; no academic results on homepage)
- about.html       About
- education.html   Education details
- skills.html      Skills and interests
- projects.html    Projects and portfolio gallery
- experience.html  Experience and activities
- contact.html     Contact information

SHARED FILES
- style.css        Colors, layout, responsive design, typography, and dark mode
- script.js        Mobile menu, theme toggle, and automatic footer year
- tania.jpeg       Profile photo used on the homepage

EDITING
1. Extract the ZIP.
2. Open the folder in Visual Studio Code or another text editor.
3. Edit page content in the matching HTML file.
4. Edit colors, fonts, spacing, and layout in style.css.
5. Edit interactions in script.js.
6. Keep tania.jpeg in the same folder as index.html, or update its filename in index.html.

GITHUB PAGES
Upload the files inside this folder to the root of your repository. In Settings > Pages, select the main branch and root folder.

IMPORTANT
Check all personal details, academic results, project descriptions, experience, and contact information before publishing. The homepage intentionally does not display academic results. See README.md for the full guide.
